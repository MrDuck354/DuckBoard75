# Custom Keyboard

Project Goals:
learn 3D modelling skills which can be applied to further projects, soldering skills which can be used in everyday life or for future career and keyboard assembly through building my own.

Im making a custom keyboard to learn how to 3D model and how to solder. 
I will learn how to use Onshape so that I can 3D print a case and maybe a plate for the keyboard.
I have never touched any software similar to Onshape so all this will provide a valuable learning experience so that I can 3D print more items in the future.
Once I have all the components and tools I will learn how to solder, I will ensure that I have a non hotswappable PCB because then it will be a lot easier to solder the switches on.
I have never used a soldering iron and I feel like it should be a skill that I should know and would be useful in the future.

building a custom keyboard is a blend between digital design and physical craftmanship. I learn multiple disciplines at once, CAD modeling, electronics and mechanical assembly whilst producing a keyboard which I will use everyday, it also gives me a clear way of knowing if I've actually learnt something through this project as 3D modelling will become easier and faster for me and I will actually know how to solder.
